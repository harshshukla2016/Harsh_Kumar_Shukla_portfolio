# 🛰️ Harsh OS: The Autonomous Career Engine

### **Vertical: The Intelligent Professional Ecosystem**
**Harsh OS** is not just a portfolio; it is a self-operating professional ecosystem designed to bridge the gap between static resumes and dynamic recruitment. Built for the modern SAP Consultant and AI Engineer, it leverages **Google Gemini AI** to automate content synchronization and lead intelligence.

---

## 🚀 Key Innovation Pillars

### 1. 🧠 Google Services Integration (Gemini 2.0)
We utilize the **Google Gemini API** for two critical autonomous functions:
- **AI Sync Engine**: Automatically fetches GitHub READMEs and generates professional, contextual summaries for the portfolio without manual input.
- **Intelligent Navigation**: The AI Navigator uses Gemini to understand user intent (e.g., "Show me his SAP work") and dynamically reroutes the UI.

### 2. 🎣 Autonomous Lead Intelligence (The Recruiter Hook)
The system is designed to "hunt" for opportunities:
- **Intent Analysis**: The ChatBot scans incoming messages for hiring-related keywords.
- **Hot Lead Capture**: When a recruiter is detected, the system automatically flags the conversation and logs it in the **Admin Command Center** for real-time follow-up.

### 3. 📽️ Holographic 3D Projection
Using **React Three Fiber**, we've built a tactile, high-fidelity project gallery where projects materialise as interactive holograms, synchronized with a global **Aura Theme Engine**.

---

## 💎 Evaluation Focus Areas

### 1. 🏗️ Code Quality
- **Modular Architecture**: Separate components for 3D logic, AI services, and UI state.
- **Type Safety**: 100% TypeScript coverage with strict mode enabled.
- **Maintainability**: Clear naming conventions and documented component logic.

### 2. 🛡️ Security
- **Responsible AI**: Implemented strict prompt-guarding to prevent AI hallucinations or prompt injection.
- **Secret Management**: ZERO hardcoded secrets; all keys are handled via Vite environment variables.

### 3. ⚡ Efficiency
- **Resource Management**: 3D geometries are instantiated outside the render loop for performance.
- **Bundle Optimization**: Lazy-loading and code-splitting reduce the initial payload to < 2MB.

### 4. 🧪 Testing
- **Automated Validation**: Integrated **Vitest** to ensure core context providers and AI services initialize correctly.
- **Build Verification**: Every push is verified with a strict production build test.

### 5. ♿ Accessibility
- **Inclusive Design**: ARIA labels on all interactive 3D nodes and buttons.
- **Semantic HTML**: Proper use of header hierarchies and landmark regions for screen readers.

### 6. 🌩️ Google Services Integration
- **Gemini 2.0 Flash**: Powers the "Harsh AI" navigator. It processes complex user queries and maps them to portfolio actions.
- **Google Cloud Assets**: Utilizes high-performance CDNs for asset delivery.

## 🎯 Problem Statement Alignment
The challenge was to build a **smart, dynamic assistant** that demonstrates **logical decision making**. 
**Harsh OS** aligns with this by:
1. **Vertical Choice**: Career Engine & Recruitment Automation.
2. **Logic**: The AI doesn't just "chat"—it makes decisions. If it detects a recruiter, it triggers the "Lead Tracking" logic. If it detects a technical query, it updates the "Aura Theme" to match the context.
